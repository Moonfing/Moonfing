# Moonfing 𖣂

Сайт-визитка TikTok-автора **@Moonfing**. Обычный статичный сайт: HTML, CSS и немного JavaScript, без сборки и без зависимостей. Работает на GitHub Pages.

## Что внутри

```
index.html        сайт (весь текст, стили и скрипты)
assets/ava.jpg    аватар
assets/cover.jpg  шапка
favicon.svg       иконка вкладки
404.html          страница «не найдено»
robots.txt        правила для поисковиков
.nojekyll         отключает обработку Jekyll
```

## Как выложить на GitHub Pages (без командной строки)

1. Зайди на [github.com](https://github.com), нажми **New repository**. Название любое, например `moonfing`. Тип **Public**.
2. На странице нового репозитория нажми **uploading an existing file**.
3. Распакуй архив и перетащи **содержимое** папки (не саму папку) в окно: `index.html`, `assets`, `favicon.svg`, `404.html`, `robots.txt`, `README.md`. Нажми **Commit changes**.
4. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветка **main**, папка **/ (root)**, нажми **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-НИК.github.io/moonfing/`.

Совет: если назвать репозиторий `ТВОЙ-НИК.github.io`, сайт будет сразу по адресу `https://ТВОЙ-НИК.github.io/`, и страница 404 будет работать правильно.

## Как подключить moonfing.kz

1. В **Settings → Pages → Custom domain** впиши `moonfing.kz` и нажми **Save**. GitHub сам добавит в репозиторий файл `CNAME`.
2. В панели, где куплен домен (например, hoster.kz или ps.kz), в DNS-записях домена добавь четыре записи **A** для `@` (корня домена):

   ```
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   ```

   Для `www` можно добавить запись **CNAME** на `ТВОЙ-НИК.github.io`.
3. Подожди от нескольких минут до 24 часов, пока обновится DNS.
4. Когда GitHub покажет, что домен проверен, включи галочку **Enforce HTTPS**.

Актуальные адреса всегда смотри в [документации GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

Важно: добавляй домен в Pages только после того, как DNS настроен. Если указать домен раньше, сайт по адресу `github.io` может временно перестать открываться.

## Как менять сайт

- **Текст**: открой `index.html`, найди нужный раздел по заголовку (`История`, `Контент`, `Telegram-канал` и т. д.) и поменяй абзац между тегами `<p>…</p>`. На GitHub можно править прямо в браузере (значок карандаша).
- **Аватар и шапка**: замени файлы `assets/ava.jpg` и `assets/cover.jpg`, сохранив названия. Лучше квадратный аватар и широкая шапка (около 1200×400).
- **Цвета**: в начале `<style>` в блоке `:root` (янтарный `--amber`, зелёный `--green-neon`).
- **Ссылки**: раздел `Ссылки` в `index.html`.

## Превью для соцсетей

Чтобы при отправке ссылки в Telegram или TikTok показывалась картинка, после подключения домена добавь в `<head>` в `index.html`:

```html
<meta property="og:image" content="https://moonfing.kz/assets/cover.jpg">
```

## Что есть на сайте

- Вход с луной, ночной фон с огнями города, звёздами, далёкой луной и силуэтом ночного города с зажжёнными окнами, плёночное зерно и виньетка.
- Заголовки «печатаются», секции появляются при прокрутке, фаза луны меняется при скролле.
- Курсор-луна со следом на компьютере (на телефоне отключён).
- Полоска прогресса чтения, счётчики статистики, падающая звезда раз в полминуты.
- Нажми на ник под именем, и он скопируется. Кнопка «наверх» появляется при прокрутке.
- Работает без JavaScript, учитывает «уменьшить движение» в настройках системы, звука нет.
